থিম

API key ম্যানেজার

যত ইচ্ছে API যোগ করো (সর্বোচ্চ 50টা)। ওপরেরটা ডিফল্ট ও সেরা। তার লিমিট শেষ হলে নিজে থেকে পরেরটা চলে, লিমিট ফিরলে আবার ওপরেরটায় ফেরে। কোনোটায় ক্লিক করে "ব্যবহার করো" চাপলে সেটাই ডিফল্ট হবে। 🔎 চালু করা API ওয়েব সার্চের কাজে আগে ব্যবহার হয়।
নতুন key যোগ
key শুধু এই ফোনেই থাকে। কাউকে দেখিও না বা শেয়ার করো না।

কীভাবে key পাবো?

যেকোনো একটা দিয়েই শুরু করা যায়। বেশি যোগ করলে একটার লিমিট শেষ হলে আরেকটা চলবে। বিনামূল্যের নিয়ম ও সীমা সাইটে সাইটে বদলায়, তাই সাইটে দেখে নাও। বাটনের নাম একটু আলাদা হলে কাছাকাছি নামেরটা খোঁজো।
Groq (শুরুর জন্য সহজ)
  1. নিচের বাটনে সাইট খুলে ইমেইল বা Google দিয়ে সাইন আপ করো।
  2. "API Keys" পেজে যাও।
  3. "Create API Key" চাপো, একটা নাম দাও।
  4. যে key দেখাবে (সাধারণত gsk_ দিয়ে শুরু) পুরোটা কপি করো। পরে আর পুরো দেখা যায় না।
  5. অ্যাপে এসে সার্ভিস "Groq" বেছে key পেস্ট করে "যোগ করো" চাপো।
Groq সাইট খোলো
Google Gemini
  1. সাইট খুলে Google অ্যাকাউন্টে ঢোকো।
  2. "Get API key" বা "Create API key" চাপো।
  3. key কপি করো (সাধারণত AIza দিয়ে শুরু)।
  4. অ্যাপে সার্ভিস "Google Gemini" বেছে পেস্ট করো।
Gemini সাইট খোলো
Mistral
  1. সাইটে সাইন আপ করো। প্ল্যান বা ওয়ার্কস্পেস বাছতে বললে বিনামূল্যেরটা নাও (ফোন যাচাই লাগতে পারে)।
  2. "API Keys" অংশে "Create new key" চাপো।
  3. key কপি করে অ্যাপে "Mistral" বেছে পেস্ট করো।
Mistral সাইট খোলো
OpenRouter
  1. সাইটে সাইন আপ করো।
  2. Keys পেজে গিয়ে "Create Key" চাপো।
  3. key কপি করো (সাধারণত sk-or- দিয়ে শুরু)।
  4. অ্যাপে "OpenRouter" বেছে পেস্ট করো। এটা ফ্রি মডেল (":free") ব্যবহার করে, যার সীমা কম হতে পারে।
OpenRouter সাইট খোলো
সাইট খুললে ব্রাউজারে যাবে। key কপি করে আবার এই অ্যাপে ফিরে এসো।
